## Features & Highlights
- **Phone Calls Suite:** Real-time incoming call alerts, dialpad, call audio bridge.
- **Messages (SMS):** Sync conversation threads, reply from PC.
- **SMB Drive Mount:** Mount Android internal storage as a native network drive in Finder / File Explorer.
- **Universal Cursor (KVM):** Seamlessly move your mouse and keyboard across devices.
- **Computer Audio Stream:** Stream lossless PC sound to your phone headphones.
- **Local Wi-Fi Mesh:** Direct peer-to-peer connection with zero cloud relay.
